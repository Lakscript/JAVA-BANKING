# SmartBank – Bank Management System

## Problem Statement

Managing customer accounts, transactions, and banking records manually can be
time-consuming and error-prone. SmartBank provides a desktop-based system to
manage these banking operations through a graphical interface.

## Scope

SmartBank covers:

- User authentication
- Account management
- Account search
- Transaction history
- Cheque deposits
- E-statement generation
- PDF statement generation
- Manager and accountant operations
- MySQL-based data storage

## Target Users

- Bank customers
- Bank managers
- Bank accountants
- Banking staff

## High-Level Features

- User Login
- Account Management
